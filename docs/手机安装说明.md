# 手机安装与演示

## 已发布下载

- [下载页面 v1.0.0](https://github.com/qxqian11-ux/tax-learning-app/releases/tag/v1.0.0)
- [直接下载签名 APK](https://github.com/qxqian11-ux/tax-learning-app/releases/download/v1.0.0/tax-learning-1.0.0-release.apk)
- 扫描交付目录 `APK下载二维码.png` 与直接下载链接效果相同。已从发布地址重新下载校验文件一致；手机仍需可访问 GitHub 的网络。

## 安装

1. 使用 `税知账-1.0.0-release.apk`，确认来源和 `SHA256SUMS.txt` 中的哈希一致。
2. 将 APK 通过 USB、文件传输发送到手机；若已经发布，也可扫描真实下载地址生成的二维码。没有发布地址时不应使用占位二维码。
3. 在手机“文件”中打开 APK，按系统提示允许该文件管理器或浏览器安装外部应用，然后安装。无需 Google Play 服务、账号或网络。
4. 华为 HarmonyOS 4.2.0 如有应用安装提示，请在系统设置中查看对应安装来源的授权和系统检测结果。不同机型菜单可能不同，保留系统防护，不必全局关闭安全检测。
5. 安装后打开“税知账·学习版”。首次有 4 笔当年模拟记录；此后删除示例也不会再生成。

最低 Android 7.0。本项目的 APK 不适用于纯鸿蒙 HarmonyOS NEXT。HarmonyOS 4.2.0 的兼容性需在目标设备上完成下面验收，未实测前不能声称已经兼容通过。

## 课堂演示建议

1. 首页点击“去查询”，选择当前年份与所得项目，查询示例记录。
2. 新增 2019 年的模拟收入，输入收入 1000.10、申报税额 10.20、已缴税额 10.20，并选择 2019 年有效日期。
3. 查询 2019 年可见新记录；其他年度不应出现该记录。
4. 打开详情，修改收入为 1200.30，回到列表查看年度统计与月度图同步变化。
5. 退出应用并从最近任务关闭，再重新打开，确认记录保留。可重启手机再检查一次。
6. 在“我的 → 数据备份与恢复”将全部年度备份到系统文件目录。
7. 重新导入同一备份，确认新增为 0、记录不重复。删除记录后恢复备份，确认恢复成功。
8. 删除前选择“取消”，记录应保留；再确认删除，只有选中记录消失。

## 数据保护与升级

卸载会删除私有数据库，卸载前先导出 JSON。CSV 供查看，JSON 才能恢复。备份没有加密，只应存储模拟资料。升级必须使用相同包名和同一发布签名，直接覆盖安装可保留数据。Debug 是独立包，不与 Release 共享数据。

## 安装失败排查

- 提示解析失败：确认下载完整、Android 版本至少为 7.0，以及设备提供 APK 兼容环境。
- 提示签名冲突：旧 APK 使用了不同密钥。先在旧版导出 JSON，再考虑卸载重装；不要直接卸载丢失数据。
- 下载网页无法访问：二维码必须基于已验证的下载链接；同学手机应单独测试访问，GitHub 在部分网络下可能连接不稳定。
