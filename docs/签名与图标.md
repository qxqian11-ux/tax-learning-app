# 签名、图标与发布

## 独立 Release 密钥

`scripts/create-signing.ps1` 调用现有 JDK keytool 生成独立 RSA 3072 / PKCS12 密钥，别名 `tax-learning`，有效期 10000 天。它不是 Android debug 密钥，也不代表任何政府或第三方认证。

`signing/tax-learning-release.p12` 与 `signing/release.properties` 需要一起离线备份，密码只在本地秘密配置中保存，不出现在源码或发布包中。脚本限制目录 ACL 为当前用户和 SYSTEM。不要把整个项目目录直接上传；源码打包脚本排除 `signing`、构建缓存和本机配置。丢失密钥将无法为已安装版本发布无缝升级。

构建缺少签名文件时 Release 会明确失败。开发调试版自动使用独立 debug 签名。验证发布签名可执行 SDK `build-tools/34.0.0/apksigner.bat verify --verbose --print-certs <APK>`。

## 自定义图标

原创“红底白色账本”图案由 Android vector XML 构成，无官方标识，不依赖生成图片或外部素材。

- Android 7 回退：`app/src/main/res/mipmap-anydpi/ic_launcher.xml`。
- Android 8+ 自适应：`mipmap-anydpi-v26/ic_launcher.xml` + `drawable/ic_launcher_foreground.xml` + `values/colors.xml`。
- 图标预览：`assets/icon.svg`，桌面导出 PNG 可通过 Android Studio Image Asset 工具生成。

替换时建议在 Android Studio 对 `res` 执行 New → Image Asset，使用独立原创图案，资源名仍为 `ic_launcher`。确保图案处于自适应图标安全区，再分别测试圆形及圆角矩形桌面蒙版。

## 下载与二维码

推荐使用自己账户下的 GitHub Releases，并从手机网络实际检查可访问性。APK 是公开发布的模拟学习应用，源代码包不应包含本地备份或签名资料。发布需要已授权的 GitHub 账户和目标仓库，工具不得虚构 URL 或将本机文件路径编码成“下载二维码”。

使用 `scripts/publish_release.py --repo 用户名/仓库名 --apk APK路径 --out output`，环境变量 `GITHUB_TOKEN` 提供该仓库的 Contents 写权限。脚本使用 HTTPS GitHub API 创建/复用 v1.0.0 Release、上传 APK，并重新下载比对 SHA-256。仅在验证一致后生成下载二维码。若同名资产已存在且内容不同，脚本停止而不会覆盖。无需将 token 写到脚本里。

二维码依赖 Python 包 `qrcode[pil]`（只在电脑生成图片，不属于 App 依赖）。GitHub 不可访问时应选择自己信任的其他 APK 托管服务，取得真实 HTTPS 地址后用 `scripts/make_qr.py` 校验下载内容再生成二维码；不能使用网盘分享页面地址冒充 APK 直链。GitHub 的免费方案及访问能力可能改变，发布时以服务实际状态为准。

也提供官方 GitHub CLI 授权发布路径：`scripts/install_github_cli.py` 从官方 Release 下载并校验便携版 CLI 到 `.gh-tools`；`GH_CONFIG_DIR` 指向 `.gh-config` 后执行 `gh auth login --web`，用户在 GitHub 官网手动完成设备授权；最后执行 `scripts/publish_from_gh.py --apk output/税知账-1.0.0-release.apk`。它会创建本人账号下的公共课程仓库，上传 APK 并核验下载内容。凭据只经进程内存传给 API，不输出到日志，`.gh-config`、`.gh-tools` 及 `signing` 都被源码打包和 Git 忽略规则排除。
