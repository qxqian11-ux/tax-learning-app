税知账 1.1.0 UI 重构说明
以用户提供的“我的”、首页、办&查、收入查询、列表与详情截图为布局参考，保留学习版独立名称和图标，所有身份和业务资料仍为模拟信息。

页面对照
我的：蓝色渐变背景、圆形自定义头像、浅橙身份卡、识别号显隐、4人/3家/1张快捷卡片、五项菜单、独立退出登录卡片。已实测关怀版切换与模拟退出/登录。
底部导航：首页、待办、办&查、消息、我的五项固定浮动导航，蓝色选中状态，按页保留滚动位置；主页横向卡片位置和资讯分类也保留。
首页：固定搜索栏、通知条、年度汇算卡、专项附加扣除卡、横向服务卡、业务介绍条、资讯分类和列表。搜索、卡片、分类和详情入口可以操作。
办&查：按办税、查询、发票管理、公众服务分组，收入明细和本机数据管理连接既有功能；末尾保留统计与 CSV/JSON 入口。
查询：居中标题、蓝色返回、年度选择底部弹层、圆形所得类型勾选、收起/展开、底部蓝色查询按钮。年度仍为 2019 至设备当前年份。保留旧“其他所得”并补充参考图中的所得类别，不修改数据库结构。
列表：白色年度汇总及记录分组、浅灰间隔、右侧所属期与箭头。收入、申报和已缴金额均来自 Room。为保留学习版功能，增加底部筛选、年度统计、新增入口；长按记录可操作。
详情：纳税明细信息、基础情况、本期收入与扣除、备注分组，蓝色查看入口，保留修改和删除。未维护的税务机构、识别号及扣除字段明确显示“未维护”或“—”，没有复制参考截图的真实资料或虚构计算金额。
新增/修改：蓝白分组表单、数字金额键盘、原日期选择器、固定保存栏和放弃修改确认。当前没有这两页的参考截图，按统一表单规范实现，仍待用户视觉核对。
待办、消息和辅助服务按任务书允许的学习版展示实现，未接入真实申报、银行、身份认证或税务服务。

与参考图的差异
头像、图标和插画为本项目自定义的本地矢量绘制，未复制官方 Logo 或政府标识。文字和数量使用模拟资料；收入展示本机真实保存的模拟记录，不复制参考图金额。保留学习版所需增删改查/备份入口，因此部分操作区会比官方截图多。没有为这些页面声称未经测量的像素级一致或还原率。
