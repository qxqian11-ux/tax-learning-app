税知账 1.2.0 任职受雇功能说明
我的 → 任职受雇进入列表。点击列表右上角“新增”或页面标题“任职受雇”，可新增一条记录。
点击任意卡片进入编辑；长按卡片弹出删除确认，取消保留、确认删除。
支持单位名称、统一社会信用代码、职务、任职受雇日期、离职日期。单位名称必填，其余可留空，列表显示“-”。日期可手填或用日历选择；离职日期不能早于任职日期。
我的页家数等于列表中实际记录条数，包含已填写离职日期的记录；编辑不增加家数，删除减一，无记录显示 0 家。
首次使用列表为空，不会复制截图中的公司资料，也不会自动生成原来写死的 3 家。
记录保存在手机应用私有的本地 Room / SQLite 数据库，退出页面、关闭 App、系统停止进程再打开后仍保留。新增数据库不迁移、不重置原收入数据库。
现有 CSV/JSON 文件备份功能仍仅包含收入明细，暂不包含任职受雇记录。卸载或清除应用数据会删除任职记录；同签名覆盖升级可保留。
列表按用户截图调整卡片及字段间距；右上角增加新增入口。编辑页没有对应参考截图，采用本项目统一蓝白表单。
